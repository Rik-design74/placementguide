# PlacementPrep AI (demo build)

A simple, fully working Next.js demo app for MBA interview prep. **No database, no
API keys, no environment setup required.** Sign up (or use the demo login),
paste a job description + resume, generate a saved "prep pack," and practice
from it.

This build intentionally has zero external services: accounts and prep packs
are stored in the browser's `localStorage`, and the prep pack itself is
generated by a deterministic, on-device function (`src/lib/generate.ts`) — no
Supabase project and no `ANTHROPIC_API_KEY` needed. It's built to be clonable
and runnable in minutes for a demo/assignment.

## Run it

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## What it does

1. Sign up or log in (`/signup`, `/login`).
2. On `/prep/new`, paste a job description and resume (each min. 200
   characters, with live counters), optionally add a company name, and pick a
   role track.
3. The app builds a "prep pack" with:
   - a 3–4 sentence fit summary
   - 3–5 gaps with how to handle each
   - ~15 practice questions across resume / functional / behavioral /
     curveball categories, each with a "what it's testing" note and a 3–5
     bullet answer skeleton (STAR for behavioral)
   - 5 questions to ask the interviewer
4. You're redirected to `/prep/[id]` to practice: check off questions,
   jot personal notes (autosaved), rename the pack inline, track progress,
   and mark it "interview-ready" once 70%+ is practiced.
5. `/dashboard` lists all your packs with progress and lets you delete them
   (with confirmation).

Guardrails: 5 generations/hour per user, plus a global daily cap
(`NEXT_PUBLIC_MAX_DAILY_GENERATIONS`, default 50) — both enforced client-side
since there's no backend.

## Deploying

Deploys to Vercel with zero configuration — no environment variables are
required. Optionally set `NEXT_PUBLIC_MAX_DAILY_GENERATIONS` to change the
daily generation cap.

## Project structure

```
src/
  app/            Next.js App Router pages (/, /signup, /login, /dashboard, /prep/new, /prep/[id])
  components/     UI components (Navbar, AuthForm, PackCard, NewPrepForm, PrepPackView)
  lib/
    db.ts         Auth + prep pack CRUD, backed by localStorage
    generate.ts   Builds a prep pack from the pasted JD + resume, on-device
    markdown.ts   "Copy as Markdown" export
    types.ts      Shared types
```

## Notes on this being a demo

- Accounts and packs live only in the browser that created them — clearing
  site data or switching browsers loses them. This is intentional: it keeps
  the app runnable with zero setup for grading/demo purposes.
- To turn this into a real production app, swap `src/lib/db.ts` for a real
  database + auth provider, and `src/lib/generate.ts` for a real LLM call —
  the rest of the app (pages, components, business flow) doesn't need to
  change.
